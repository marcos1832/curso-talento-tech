# Mi Tienda

Este proyecto es una página web de una tienda, realizada como parte de una pre-entrega de desarrollo web.

La página cuenta con:

- Una sección de inicio.
- Un menú de navegación.
- Una sección de productos.
- Una sección de reseñas.
- Un formulario de contacto realizado con Formspree.
- Diseño adaptable para celular y computadora.

## Tecnologías utilizadas

- HTML
- CSS
- Google Fonts
- Flexbox
- Grid
- Media Queries

## Archivos

- `index.html`: contiene la estructura de la página.
- `styles.css`: contiene los estilos.
- `README.md`: contiene información sobre el proyecto.
